# DBD 3.7.2: общий бан-лист

`bans.signed.json` — подписанный список SteamID64 для хостов локальной сборки DBD 3.7.2, начиная с обновления 24. Это не бан в Steam или официальной игре.

Сервер проверяет подпись Ed25519 встроенным публичным ключом и обновляет список при запуске и каждые 5 минут. При сетевой ошибке сохраняется последняя проверенная копия. Старая ревизия и изменение без подписи отклоняются. Локальные баны дополнительно применяются каждым хостом.

Владелец добавляет и снимает общие баны через «Общие баны DBD.bat» на своём ПК, нажимает «Подписать для GitHub», затем загружает подготовленный `bans.signed.json` в эту папку и подтверждает Commit changes. Не редактируйте подписанный JSON вручную.

Личный ключ хранится только в профиле Windows владельца, за пределами игры и этого репозитория. Не публикуйте его и не включайте в архив для игроков. В игровых сборках нет токена GitHub.

Начальная ревизия 1 пуста: аккаунты автоматически не банились. Общий список запрещает вход через поддерживаемый backend у обновлённых хостов, не гарантируя кик из уже идущего матча или защиту от намеренно модифицированного клиента/хоста.
